# FlowGate collaboration lab

Public, synthetic experiment for issue/PR conventions, shared agent instructions,
skills, worktrees, CI, review and acceptance. This is not FlowGate application code
and contains no coursework documents, real tenants, provider credentials or data.

Runtime: Python 3.13, standard library only. Run `python -m unittest discover -s tests -v`.

The intentionally limited access and accounting examples provide tasks for agents.
Passing these examples does not establish FlowGate security or compatibility.
See `CONTRIBUTING.md`, `AGENTS.md` and `docs/experiment.md` for the experiment.
